# Outbound Transport Inventory & Policy

This inventory records every outbound HTTP/network call site across `packages/` and `apps/` with its assigned trust decision and transport posture.

| File / Component                              | Target / Use Case                                       | Transport Posture                                 | Decision & Justification                                                                                                                                                                                   |
| --------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apps/server/src/main.ts`                     | HTML / Page retrieval (`fetchPage`)                     | `pinned safe-fetch`                               | Main research fetch pipeline uses `safeFetch` with pinned transport (SRC-23) + site-access policy per hop. Hermetic tests inject `deps.fetchImpl`.                                                         |
| `apps/server/src/main.ts`                     | Marginalia search API (`createMarginaliaSearch`)        | `pinned-fetch wrapper`                            | Wrapped via `pinnedFetch` using site-access policy + pinned-IP transport (SRC-24). Standard headers attached.                                                                                              |
| `apps/server/src/main.ts`                     | Wikipedia API & Extracts (`createWikipediaSearch`)      | `pinned-fetch wrapper`                            | Wrapped via `pinnedFetch` using site-access policy + pinned-IP transport (SRC-24). Standard headers attached.                                                                                              |
| `apps/server/src/main.ts`                     | OpenAI-compatible model API (`createOpenAICompatModel`) | `configured transport / host-local`               | Direct model synthesis call. When host-local (e.g. Ollama `http://127.0.0.1:11434`), explicitly allowed loopback. Remote model endpoints require approved transport configuration or injected `fetchImpl`. |
| `packages/auth/src/oidc.ts`                   | OIDC JWKS / Discovery (`JwksOidcVerifier`)              | `explicitly trusted loopback or configured fetch` | Identity verification fetch for OIDC discovery / JWKS keys. Takes optional `fetchImpl` (defaults to global fetch for loopback/trusted proxy auth).                                                         |
| `packages/storage/src/fastembed-embedder.ts`  | Model files download (`ensureModelFiles`)               | `explicit safe-fetch seam / test transport`       | Downloads ONNX model files from HuggingFace to `.fastembed_cache/` if missing. Updated to use safe-fetch or explicit fetch transport.                                                                      |
| `packages/plugins/plugin-search-marginalia`   | Search provider HTTP requests                           | `injectable FetchLike`                            | Defaults to platform `fetch` (bound to `pinnedFetch` by `apps/server/src/main.ts` in live composition).                                                                                                    |
| `packages/plugins/plugin-search-wikipedia`    | Search provider HTTP requests                           | `injectable FetchLike`                            | Defaults to platform `fetch` (bound to `pinnedFetch` by `apps/server/src/main.ts` in live composition).                                                                                                    |
| `packages/plugins/plugin-model-openai-compat` | Model provider HTTP requests                            | `injectable FetchLike`                            | Defaults to platform `fetch` (bound to host-local Ollama or `pinnedFetch` in live composition).                                                                                                            |
