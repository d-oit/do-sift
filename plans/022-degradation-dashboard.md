# 022 — Degradation honesty on the evals dashboard (DEG-04)

Status: done (2026-11-02). Follow-up to plans 020/021 (issue #127).

## Goal

Make degradation behavior visible where quality history already lives: the
static dashboard generated by `npm run evals:dashboard`. The suite's
`latest.json` artifact gains each scenario's expected reason, and the
dashboard renders score, pass counts, and a reason breakdown.

## Task table

| ID     | Task                                                       | Status |
| ------ | ---------------------------------------------------------- | ------ |
| DEG-04 | Surface degradation-honesty score and reasons in dashboard | done   |

## Changes

- `scripts/degradation/run.ts`: `DegradationScenarioResult` carries the
  scenario's expected `reason` and `degraded` flags (metadata only — no new
  assertions, so the honesty score is unchanged).
- `scripts/evals-degradation.ts`: artifact records `degraded` and `reason`
  per scenario.
- `scripts/evals-dashboard.ts`: `loadDegradationArtifact()` reads
  `evals/degradation/latest.json`; `buildDashboardHtml()` renders a
  "Degradation Honesty (failure-mode suite)" panel with the score, reason
  counts, and per-scenario rows. A missing artifact renders instructions
  instead of failing the dashboard.
- `evals/dashboard/index.html`: regenerated.
- `tests/unit/evals-dashboard.test.ts`: panel rendering + artifact loading
  (present and absent) coverage.
- `docs/quality-gate.md`: scenario count corrected to seven and the
  dashboard panel is named as the place to read the score.

## Acceptance

- Dashboard shows `degradationHonesty`, passed/total, and one row per
  scenario with its expected reason.
- Missing artifact is explicit, not an error.
- `npm run check` stays green (the existing gate keeps enforcing 1.0).

## Evidence

Commands run 2026-11-02 from the repo root:

- `npm run check` → exit 0, 9/9 PASS.
- `npx vitest run tests/unit/evals-dashboard.test.ts` → exit 0, all pass.
- `npm run evals:dashboard` → dashboard regenerated.
- `npm run evals:degradation` → 7/7, score 1.000, artifact includes reasons.

## Risks

- The dashboard is a static report over committed artifacts; it does not
  query live traffic. Reason counts describe the pinned suite, not
  production incidence.
- `latest.json` remains a single-snapshot artifact (no history), so the
  panel shows current suite health rather than a trend.
